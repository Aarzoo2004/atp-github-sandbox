# ATP GitHub Connector Sandbox

This repository is used to test the ATP GitHub connector against the real GitHub API.

## Purpose

This repository provides safe test data for:

- Repository operations
- Branch operations
- Commit operations
- File operations
- Issue operations
- Pull request operations
- GitHub Actions
- Releases
- Search
- GraphQL
- Permissions and authentication

## Test Repository

This repository is disposable and may be modified by automated connector tests.
